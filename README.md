# VaultBackupPro

**VaultBackup Pro 1.2.0** は、Minecraft サーバー向けの無料・GPLv3 バックアッププラグインです。「復元予約 → 自分で通常停止 → 完全終了後に復元 → 手動起動」に対応し、日本語・英語の表示を選べます。

配布 JAR は **VaultBackupPro-1.2.0.jar**。このリポジトリに対応ソースとビルド手順を含みます。配布物の識別は [SHA-256 と検証結果](TEST-RESULTS.md)、ソース・公開ファイル名については [配布情報](PUBLICATION-NOTES.md) を確認してください。

English guide: [QUICKSTART-EN.md](QUICKSTART-EN.md).

## プレリリース（テスト版）・必須の起動条件

この 1.2.0 はプレリリースのテスト用配布です。ホストの自動再起動を無効にし、復元ヘルパーの完了と終了を確認してから手動起動してください。復元処理中に別のサーバーを起動する運用は未対応です。Paper はプラグインの停止要求後にもワールドを書き込むことが実測されており、プラグインだけではその競合によるデータ破損を防げません。ホスティング側の設定を確認できない環境で本番安全を保証しません。

## 対応環境
Minecraft Java 26.2 / 26.3、Paper / Purpur / Spigot、Java 25。実際に検証したビルドと最終 JAR の SHA-256 は TEST-RESULTS.md と docs/RUNTIME-TEST-RESULTS.md を参照してください。Purpur 26.3 は上流で experimental 扱いです。本版の Spigot は共通 API コンパイルのみ確認し、実サーバー試験は準備未完了です。Windows と実クライアント GUI は未検証です。

## 主な機能
- 管理者用のチェスト GUI、コマンド、バックアップ一覧・情報・容量表示
- 作成ボタンで即受付。保存中の案内をすぐ表示し、圧縮は非同期で実行
- サーバールートを対象とする ZIP バックアップ、SHA-256 と各ファイルの検証
- 設定した件数・容量で自動整理。最後の 1 件も整理対象です
- 削除・復元予約は操作ボタンまたはコマンドで直接受付。追加確認画面なし
- 停止前に取り消せる復元予約。予約操作でサーバーを停止しません
- 完全な JVM 終了を確認する独立ヘルパー、元のサーバーツリーの退避、失敗時の保護
- 日本語を標準に、設定で英語へ切替可能
- Discord 通知は任意設定。標準では無効です

## 最初に読む文書
INSTALL.md → COMMANDS.md → CONFIGURATION.md。運用前に TEST-RESULTS.md、KNOWN-LIMITATIONS.md、docs/OFFLINE-RESTORE.md を必ず確認してください。

## 操作時の注意
削除は追加確認なしで実行され、取り消せません。最後のバックアップも手動・自動整理で削除できるため、0 件になる場合があります。独立したバックアップも保管してください。

復元ボタンを押すと検証後すぐに次回停止時の復元が予約されます。不要になったら停止前に `/backup restore cancel` を実行し、取消完了を確認してください。

## 大切な制約
稼働中のバックアップは、別プラグインのデータベースや外部書込みまで原子的に止めるファイルシステムスナップショットではありません。それらは個別に保存・停止してください。

復元は対象 ZIP に含まれるツリーでサーバールートを置き換えます。除外ファイルは新しいツリーへ混在させず、復元前の退避ツリーに残します。バックアップと復元状態はサーバールート外に置きます。ホスティング側の自動再起動・監視再起動を止め、ヘルパー完了前に再起動しないでください。

古いバックアップには、その時点のプラグイン JAR と設定も入っています。以前の版を含むバックアップを復元すれば、プラグイン自体も以前の動作・言語設定へ戻ります。復元後にどの改訂が入っているかを確認してください。
