# VaultBackupPro

**VaultBackup Pro 1.1.0** は、Minecraft サーバー向けの無料・GPLv3 バックアッププラグインです。「復元予約 → 自分で通常停止 → 完全終了後に復元 → 手動起動」に対応し、日本語・英語の表示を選べます。

配布 JAR は **VaultBackupPro-1.1.0.jar**。このリポジトリに対応ソースとビルド手順を含みます。配布物の識別は [SHA-256 と検証結果](TEST-RESULTS.md)、ソース・公開ファイル名については [配布情報](PUBLICATION-NOTES.md) を確認してください。

English guide: [QUICKSTART-EN.md](QUICKSTART-EN.md).

## 対応環境
Minecraft Java 26.2 / 26.3、Paper / Purpur / Spigot、Java 25。実際に検証したビルドと最終 JAR の SHA-256 は TEST-RESULTS.md と docs/RUNTIME-TEST-RESULTS.md を参照してください。Purpur 26.3 は上流で experimental 扱いです。

## 主な機能
- 管理者用のチェスト GUI、コマンド、バックアップ一覧・情報・容量表示
- サーバールートを対象とする ZIP バックアップ、SHA-256 と各ファイルの検証
- 自動バックアップと保持制限では最後の正常な 1 世代を保護
- 手動削除は最後の 1 件でも、バックアップが 0 件になる警告を確認して削除可能
- 停止前に取り消せる復元予約。通常の予約確定操作ではサーバーを停止しません
- 完全な JVM 終了を確認する独立ヘルパー、元のサーバーツリーの退避、失敗時の保護
- 日本語を標準に、設定で英語へ切替可能
- Discord 通知は任意設定。標準では無効です

## 大切な制約
稼働中のバックアップは、別プラグインのデータベースや外部書込みまで原子的に止めるファイルシステムスナップショットではありません。それらは個別に保存・停止してください。

復元は対象 ZIP に含まれるツリーでサーバールートを置き換えます。除外ファイルは新しいツリーへ混在させず、復元前の退避ツリーに残します。バックアップと復元状態はサーバールート外に置きます。ホスティング側の自動再起動・監視再起動を止め、ヘルパー完了前に再起動しないでください。

古いバックアップには、その時点のプラグイン JAR と設定も入っています。以前の版を含むバックアップを復元すれば、プラグイン自体も以前の動作・言語設定へ戻ります。復元後にどの改訂が入っているかを確認してください。
