# VaultBackup Pro 1.2.1 — プレリリース

セキュリティの強化・不具合修正。1.2.0 をお使いの場合は更新を推奨します。

- 新しいバックアップ ZIP と付属情報は、所有者のみ読み書き可能（0600）で作成します（Linux/macOS）。別ユーザーでバックアップを読み取る運用では権限を確認してください。既存ファイルの権限は変更しません。
- 削除は確認画面なしで実行され、取り消せません。保持設定によってバックアップが0件になります。
- ホストの自動再起動を無効にし、復元ヘルパーの SUCCESS と終了を確認してから手動起動してください。復元中の同時起動は未対応です。
- 本版は実サーバー試験を再実施していません。Spigot 実行、Windows、実クライアント GUI も未確認。Purpur 26.3 は experimental です。

無料 GPLv3。難読化 JAR と対応ソースを同梱。Java 25、詳細な使用条件・検証範囲は README と TEST-RESULTS を参照してください。
