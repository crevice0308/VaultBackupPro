# VaultBackup Pro 1.2.0 — プレリリース

操作性の改善・不具合修正。

- 削除は確認画面なしで実行され、取り消せません。保持設定によってバックアップが0件になります。
- ホストの自動再起動を無効にし、復元ヘルパーの SUCCESS と終了を確認してから手動起動してください。復元中の同時起動は未対応です。
- 本版の Spigot 実行、Windows、実クライアント GUI は未確認。Purpur 26.3 は experimental です。
